# The Weather Shop

Unity 6.6.7f1 browser-game prototype for CrazyGames.

## Phase 1 controls

- **WASD / Arrow keys / left stick:** move
- **E / gamepad south button:** collect a mote or deliver weather to a nearby garden

## Local development

Open this folder with Unity `6000.6.7f1`:

```text
C:\Users\RIYAN\Desktop\Ex\GamEX\TheWeatherShop
```

The parent `GamEX/opencode.jsonc` contains the project-local Unity MCP relay configuration.
No global skill or MCP configuration is required.
